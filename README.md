# Apocalypse Trail

A Windows convoy survival game. Keep the survivors supplied, customize your vehicles, search abandoned districts, and follow the beacon across the ash roads.

[Download the Windows installer](https://github.com/Dkillington/ApocalypseTrail-Releases/releases/latest/download/Dkillington.ApocalypseTrail-win-Setup.exe)

[Portable ZIP](https://github.com/Dkillington/ApocalypseTrail-Releases/releases/latest/download/Dkillington.ApocalypseTrail-win-Portable.zip) · [Release notes and checksums](https://github.com/Dkillington/ApocalypseTrail-Releases/releases)

The installer includes the required runtime and adds desktop and Start menu shortcuts. Windows x64 is required.

## Updates

Open **Settings → Updates** to see the installed version and release notes. The game checks at startup and every six hours by default. Choose **Download update**, then **Save & restart to update** when ready. Your current convoy is saved and restored after restart.

A portable or development copy can download the official installer from the same screen to enable installed updates. Saves stay in `%LOCALAPPDATA%\ApocalypseTrail\Saves` and carry over to the installed game.

This repository hosts player downloads and the update feed. The application source is maintained separately.
